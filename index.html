⚙️ Conexión con Google Sheets

Configurá el Sheet donde se registran las escuelas

Pasos para activar el registro automático:
1. Creá un Google Sheet (puede ser nuevo o existente)
2. Abrí el Sheet → Extensiones → Apps Script
3. Pegá el código del archivo apps-script.gs
4. Implementar → Nueva implementación → Aplicación web
   · Ejecutar como: Yo
   · Quién accede: Cualquier usuario
5. Copiá la URL y pegala arriba
6. Para ver los datos en el admin: Archivo → Compartir → Publicar en la web
   · Publicá cada hoja por separado: "Escuelas" y "Registro"
   · Formato: CSV en ambas
7. Copiá el ID de la URL del Sheet y pegalo arriba

⚠️ Importante: si la hoja "Registro" no aparece, verificá que esté publicada como CSV en "Publicar en la web".
